# 漫改动画全流程生产管线 (Manga-to-Anime Pipeline: Blender -> Krita -> AE) — 人类最高宪章 (`INSTRUCTIONS.md`)

> [!IMPORTANT]
> 本文件由用户拥有所有权，Agent 在 `/study`、`wiki-refine` 和日常执行中**必须首先读取并遵守本文件**，但未经用户明确授意**严禁覆写本文件**。

## 核心关注方向与审美优先级
- **模块定位**: 从漫画分镜解析 -> Blender 3D场景透视与机位 -> Krita原画关键帧、清线与赛璐珞上色 -> AE摄影后期合成。
- **质量原则**: 优先提炼可复用的结构化方法论与可量化的 Verifier/Generator 脚本，拒绝空洞的形容词堆砌。
- **跨层强制联动**: 执行本模块任何任务时，必须同步加载关联底层学科：`foundations/narrative_dramaturgy`, `foundations/cinematography_staging`, `foundations/visual_aesthetics`, `foundations/motion_animation`。
